# Inventaire Mobile App (PWA)

Prototype d'application mobile pour la gestion d'inventaire client.

- Accès à l'inventaire
- Ajustements, entretien, corrections
- Section contrat
- Envoi de dossiers
- Chat d'échange

Liée conceptuellement à une page Notion (plan gratuit du client) et à un moteur de calcul Excel via robots hébergés.

## Installation

1. Hébergez ces fichiers (GitHub Pages, Vercel, Netlify...).
2. Ouvrez l'URL sur mobile.
3. Ajoutez à l'écran d'accueil (PWA).
